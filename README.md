
# Serverless Resume API on AWS

## Project Overview
A serverless REST API that provides professional resume information using AWS services.

## Technologies Used
- Python
- AWS Lambda
- Amazon API Gateway
- Amazon DynamoDB
- AWS CloudFormation
- JSON

## API Endpoints
- GET /personal
- GET /experience
- GET /education
- GET /skills

## Features
- Serverless backend
- Resume data storage
- API key authentication
- API throttling
- Infrastructure as Code
